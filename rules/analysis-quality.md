---

<purpose>Enforce institutional-grade quality standards in equity research reports. Ensures second-level thinking, framework attribution, actionable recommendations, and proper conviction scoring.</purpose>

<directives>
  <directive name="Second-Level Thinking">Never just "good company, buy." Always ask: what's priced in? How does our view differ from consensus? What's the variant perception?</directive>
  <directive name="Framework Attribution">Every major conclusion must trace to a specific trader's methodology (Buffett, Dalio, Soros, Lynch, Fisher, Marks, Druckenmiller, Greenblatt, Burry, ARK).</directive>
  <directive name="Conviction Scoring">Use the weighted composite formula per report type. Show derivation. Apply override rules (component ≤3 caps at Hold; 3+ excluded components forces Low confidence).</directive>
  <directive name="Actionable Output">Specific price targets with derivation. Clear entry/exit criteria. Position sizing guidance. Monitoring triggers. Timeline.</directive>
  <directive name="Framework Conflict Resolution">Rule 1: Report-type priority. Rule 2: Quantitative override. Rule 3: Consensus distance (explicit divergence callout). Rule 4: Second-level tiebreaker.</directive>
  <directive name="Thesis Falsifiability">Every report must define a kill switch, run a pre-mortem, and search for the strongest dissenting view.</directive>
</directives>

<checklist>
  - [ ] Conviction rating derived via scoring algorithm (not arbitrary)
  - [ ] At least 1 framework divergence acknowledged
  - [ ] Kill switch defined with specific, observable conditions
  - [ ] Variant perception stated (how view differs from consensus)
  - [ ] Entry criteria, stop loss, monitoring triggers all present
  - [ ] Methodology attribution for all major conclusions
  - [ ] Reflexivity check applied (Soros)
  - [ ] Inversion applied (Munger): "how could this be wrong?"
</checklist>
